Which creative direction for the ORCA Marine reimagining?

Same content (mission, agents, demo, team), same hero video — different visual language and layout structure.

bioluminescent depth

A — Deep Current

Near-black ocean gradients, glassmorphic panels, a single bioluminescent cyan glow that pulses through sections. Asymmetric, overlapping layout — content feels like it's suspended in water. High drama, high motion.

grid / telemetry

B — Field Instrument

Scientific-instrument aesthetic: nautical-chart grid lines, monospace data readouts, coordinate labels, hairline borders. Feels like a live sensor console for the agents rather than a marketing page. Restrained color, information-dense.

Editorial

C — Tidal Editorial

Magazine-style: oversized serif/display type, generous whitespace, warm off-white base instead of dark mode, ocean-blue as the single accent. Asymmetric magazine grid with pull-quotes for agent descriptions. Calmer, more editorial than techy.
