How should the 8 agents be presented?

Same 8 agents, same accurate live/mock/mixed status per agent — just how it's laid out visually in Deep Current.

A — Sonar radar map

8 agents plotted as blips on a radar/sonar circle, color-coded live (cyan) vs mock (amber/dim). Clicking a blip expands a detail panel. Most distinctive, but needs the labels/details to stay readable — riskier for a text-heavy status table.

AGENT      STATUS   SOURCE

OCEAN     ○ MOCK   INCOIS gated
GEOSPATIAL  ● LIVE   Marine Regions

B — Data-console rows

Terminal-style row list, monospace, one row per agent — status dot + live/mock label + data source, expandable on click for the full description. Reads as a real instrument readout (fits the "field instrument" undertone within Deep Current). Very scannable.

C — Depth stack

Agents listed as a descending staggered stack, each bar offset deeper (literal "diving deeper" metaphor), color = live/mock. Scroll-driven reveal as you go down the page. Strong visual metaphor tying back to the ocean theme, but the least conventional to scan quickly.
