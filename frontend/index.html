The Problem

Coasts Don't
Come With
A Manual

A fisherman deciding whether to go out today is working from scattered PDFs, word of mouth, and whatever bulletin made it to shore in time. Weather, sea state, fishing zones, and maritime boundaries live in different systems, updated on different schedules, in different formats — none of it built for a quick decision at 4 a.m. before a boat leaves harbor.

ORCA Marine puts one question in front of a coordinating layer of AI agents — weather, ocean analytics, geospatial, risk — each pulling from the live source it actually knows, and returns one answer with the evidence attached. Not a guess dressed up as one.

01

Every answer carries evidence — source and timestamp. If nothing can be grounded, ORCA refuses to answer. It never guesses a forecast, and it never guesses a maritime boundary.

05 Live

Data Discovery Agent

The one place every live call, fallback, and evidence stamp actually happens. The other agents never touch a data source directly.

06 Live

Memory / Session Agent

Resolves follow-up questions like “what about the wind speed?” using the prior turn — never overrides an explicit new topic.

07 Live

Reporting Agent

Renders a self-contained HTML report with a Leaflet map and full evidence table for every grounded answer.

08 In Progress

Risk Assessment Agent

Synthesizes weather, ocean, and geospatial signal into one hazard score. No new data source needed.

The Platform

Checked,
Not Trusted
On Faith

Backend

FastAPI + Pydantic. One /query endpoint, typed contracts end to end, 22 pytest tests via dependency injection.

Live Data

Open‑Meteo for weather and wave height. Marine Regions for maritime boundaries. Both free, no key, verified reachable.

Gated Data

INCOIS has no public API. WDPA needs a registration token. Both run on clearly‑labelled mock data, never silently faked.

Intent Layer

OpenAI first, keyword rules on failure or no key. Every response reports which path answered — auditable, not hidden.
